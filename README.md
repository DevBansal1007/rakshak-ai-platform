# 🛡️ Rakshak AI

> AI-Powered Fraud Early Warning and Intelligence Platform

## 📌 Problem Statement

Rakshak AI is being developed as part of an AI Hackathon under the theme:

**AI for Digital Public Safety: Defeating Counterfeiting, Fraud & Digital Arrest Scams**

The platform helps citizens identify suspicious messages, screenshots, documents, and call recordings before financial loss occurs while providing actionable fraud intelligence for law enforcement.

---

## 🚀 Key Features

- Scam Risk Analysis
- OCR-based Document Analysis
- Speech-to-Text Scam Analysis
- Entity Extraction
- Fraud Early Warning Engine
- Complaint Report Generation
- Fraud Intelligence Dashboard
- Geospatial Crime Visualization
